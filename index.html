دليل التثبيت والربط

ربط الشيت (مرة واحدة، 5 دقائق)
  1. افتح شيت الطلبيات في Google Sheets (أو شيت جديد فارغ).
  2. من القائمة: Extensions / الإضافات ← Apps Script.
  3. احذف كل ما في ملف Code.gs والصق كود السكربت كاملاً.
  4. اضغط Deploy ← New deployment، النوع Web app، مع Execute as: Me و Who has access: Anyone، ثم Deploy ووافق على الصلاحيات.
  5. افتح رابط Web app: هذا موقعك. ادخل بـ ADMIN / 1234 ثم غيّر كلمة السر من "حسابي".
  6. عند أول دخول ينشئ البرنامج أوراق النظام في الشيت (تبدأ بـ CRM_): المستخدمين، الزبائن المحتملين، القوالب، المهام، سجل التواصل، الإعدادات.
عند تحديث الكود لاحقاً: Deploy ← Manage deployments ← تعديل ← Version: New version، حتى يبقى الرابط نفسه.
ربط شركة التوصيل (Ecotrack)
  1. من لوحة تحكم شركة التوصيل (منصة Ecotrack) أنشئ API token من الحساب ← API. إذا لم تجده اطلب تفعيله.
  2. رابط المنصة هو رابط لوحة التحكم، مثل https://xxxx.ecotrack.dz.
  3. ضعهما في ECOTRACK_URL و ECOTRACK_TOKEN أعلى السكربت، ثم انشر نسخة جديدة.
التوكن يبقى داخل حسابك في Google ولا يظهر في المتصفح أبداً.
